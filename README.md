## 🛠️ Key Features

This project was built from the ground up in Unity, focusing on creating a genuinely terrifying experience through code and mechanics:

* **Advanced Horror AI:** A state-machine-driven enemy that patrols, investigates last known locations, and performs a tension-building "stare" before chasing the player.
* **Cinematic Jumpscares:** Custom camera-snapping jumpscare routines with dynamic animations and audio routing.
* **Universal Interaction System:** A robust, raycast-based interaction architecture. The player can look at anything (doors, drawers, keys) and interact seamlessly using interfaces.
* **Procedural Camera Effects:** Heavy, realistic first-person movement featuring figure-8 head bobbing, idle breathing, and procedural camera sway based on player speed and states.
* **Immersive UI:** A fully functional main menu and an asynchronous loading screen to keep the tension high between scenes.

## 💻 Tech Stack & Mechanics Details

* **Engine:** Unity (2022.x or later recommended)
* **Input:** Unity New Input System
* **Navigation:** Unity NavMesh Agent (for AI pathfinding)
* **Physics:** Custom hollow colliders for realistic drawer/cabinet interactions.

## 🚀 How to Run the Project (For Developers)

If you downloaded the project files via the Mega link above and want to open it in Unity:

1. Extract the downloaded `.zip` file.
2. Open **Unity Hub**.
3. Click **Add project from disk** and select the extracted folder.
4. Once the project opens, navigate to `Assets/Scenes/`.
5. Open the **MainMenu** scene.
6. Make sure all scenes (`MainMenu`, `LoadingScene`, `GameScene`, `GameOverMenu`, `WinMenu`) are added to **File > Build Settings**.
7. Press **Play**!
